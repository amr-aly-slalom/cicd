# Data Model: Shared KMS Key for Multiple Similar Service Principals

**Feature**: `004-shared-kms-service-principals`
**Date**: 2026-06-30

---

## Entity 1: KMS Service Entry (configuration record)

Defined in: `terraform/locals.tf` → `local.kms_services`

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `key` (map key) | `string` | Unique within `kms_services`; used in alias and key description | Logical service name, e.g. `cloudwatch_logs` |
| `service_principals` | `set(string)` | ≥ 1 element; duplicates silently collapsed to unique set | One or more AWS service principal identifiers |

**Before this feature** (old shape):
```hcl
kms_services = {
  cloudwatch_logs = {
    service_principal = "logs.us-east-1.amazonaws.com"   # single string
  }
}
```

**After this feature** (new shape):
```hcl
kms_services = {
  cloudwatch_logs = {
    service_principals = ["logs.us-east-1.amazonaws.com"]   # set(string), ≥1 element
  }
}
```

**Existing entries** (all updated atomically):

| Entry key | `service_principals` value |
|-----------|---------------------------|
| `redshift` | `["redshift.amazonaws.com"]` |
| `sns` | `["sns.amazonaws.com"]` |
| `cloudwatch_logs` | `["logs.<region>.amazonaws.com"]` |
| `msk` | `["kafka.amazonaws.com"]` |

---

## Entity 2: KMS Module Variables

Defined in: `terraform/modules/kms/variables.tf`

| Variable | Type | Constraints | Description |
|----------|------|-------------|-------------|
| `service_name` | `string` | Required; no change | Used in alias name and key description |
| `service_principals` | `set(string)` | Required; `length ≥ 1` (validated) | Set of AWS service principal identifiers; **replaces** `service_principal` |
| `environment` | `string` | Required; no change | Terraform workspace name |

**Validation rule** (new):
```
length(var.service_principals) > 0
→ error: "At least one service principal must be provided."
```

---

## Entity 3: KMS Key Policy Document

Generated by: `data "aws_iam_policy_document" "this"` in `terraform/modules/kms/main.tf`

| Statement | Principal type | Principals | Actions |
|-----------|---------------|-----------|---------|
| `EnableIAMUserPermissions` | `AWS` | Root account ARN (unchanged) | `kms:*` (unchanged) |
| `AllowServiceAccess` | `Service` | `tolist(var.service_principals)` — all declared principals | 6 named actions (unchanged) |

**Change**: `identifiers` in `AllowServiceAccess` changes from `[var.service_principal]` to `tolist(var.service_principals)`.

When `service_principals` has one element, `tolist({"x"})` produces `["x"]` — identical JSON to the previous `[var.service_principal]`.

---

## Entity 4: AWS Resources Produced (per `kms_services` entry)

| Resource | Type | Key in `for_each` | Change behaviour |
|----------|------|-------------------|-----------------|
| `aws_kms_key.this` | `aws_kms_key` | `service_name` | Key policy updated **in-place** when principals change (no replacement, no key rotation trigger) |
| `aws_kms_alias.this` | `aws_kms_alias` | `service_name` | Unchanged; alias name always `alias/chedaws-edp-{service_name}-{environment}` |

---

## State Transitions

### Adding a second service principal to an existing entry

```
Before:  service_principals = {"logs.us-east-1.amazonaws.com"}
After:   service_principals = {"logs.us-east-1.amazonaws.com", "logs.eu-west-1.amazonaws.com"}

Plan result:
  ~ aws_kms_key.this (key policy updated in-place)
  No aws_kms_alias changes
  No key replacement
```

### Declaring duplicate principals (silently deduplicated)

```
Input:   service_principals = ["logs.us-east-1.amazonaws.com", "logs.us-east-1.amazonaws.com"]
Stored:  set(string) = {"logs.us-east-1.amazonaws.com"}   (one element)
Plan result: equivalent to single-element declaration; no error raised
```

### Empty set (rejected at plan time)

```
Input:   service_principals = []
Result:  terraform plan → validation error:
         "At least one service principal must be provided."
         No AWS API calls made.
```
